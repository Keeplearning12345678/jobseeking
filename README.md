# 求职工作台 · 单文件版

把两张 markdown 台账变成**一个双击就能打开、不联网、不需要服务器**的求职工作台网页。

- 数据存在你自己的 markdown 里（`求职/已投递的公司.md`、`求职/面试.md`），改完重跑一条命令就更新；
- 构建出来的 `工作台.html` 是**单文件**（数据已内嵌），可以拷到手机、U 盘、发给别人看；
- 页面里的「阶段覆盖 / 跟进日期 / 笔记 / 练习记录」存在浏览器本地，**不写回 markdown**。

> 包里自带一份**示例台账**（6 家虚构公司：示例能源集团 / 示例重工装备 / …），
> 直接双击 `工作台.html` 就能看到完整效果。看完把示例换成你自己的即可。

📖 **第一次用先读 `快速上手.md`**（10 分钟，含「手上只有一张 Excel 表」的零安装做法）；
要 AI 帮你把零散记录（截图 / 邮件 / 聊天记录）整理成台账看 `用-AI-录入.md`；手写台账照 `台账模板.md`。
想改封面 / 配色 / 文案 / 阶段叫法（不用动代码）看 `个性化说明.md`。

## 一、30 秒上手

```bat
:: ① 装 Node.js（有就不用管）：https://nodejs.org  → 装 LTS 版
:: ② 在**本文件夹**里打开命令行（地址栏输 cmd 回车），跑：
node build.mjs --scrape
:: ③ 双击生成的 工作台.html
```

`node build.mjs --scrape` 做两件事：抓取 markdown → `cache.json`，再把 `cache.json` 注入
`app.html` → `工作台.html`。

之后：

| 你改了什么 | 跑哪条命令 |
|---|---|
| `求职/*.md` 台账 | `node build.mjs --scrape` |
| `app.html`（页面本身） | `node build.mjs`（用缓存重建，快） |
| `assets/hero.jpg`（首页封面图） | `node build.mjs`（图片会内联进 HTML） |

> 不装 Node 也能用：`工作台.html` 可以直接发出去、双击打开。
> 只有**改数据**才需要 Node。

## 二、文件说明

| 文件 | 是什么 | 要不要改 |
|---|---|---|
| `工作台.html` | 构建产物：单文件工作台，双击即用 | ❌ 自动生成，别手改（重跑会覆盖） |

| `求职/已投递的公司.md` | **你的主台账**（名单 / 行业线 / 已放弃 / 逐家详情） | ✅ 主要就写这个 |
| `求职/面试.md` | 通用问答 + 逐家速查 + 公司口碑 | ✅ 第二个要写的 |
| `assets/hero.jpg` | 首页封面图 —— **想换封面就只换这一个文件** | ✅ 想换就换 |
| `快速上手.md` | **第一次用先读这个**：10 分钟上手（先看示例 → 录自己的 → 每天看哪一栏）+ 五个常见的坑 | 📖 读 |
| `个性化说明.md` | 顶栏 🎨 那个面板：封面 / 文案 / 配色 / 阶段名 / 栏目 / 首页读数怎么改，怎么带给别人 | 📖 读 |
| `台账模板.md` | 空白台账骨架（五小节 + 字段说明 + 九档阶段词表），**复制一份改名就能填** | ✏️ 填 |
| `用-AI-录入.md` | 让 AI（Codex / ChatGPT / DeepSeek…）把零散记录整理成台账的提示词 + 产出自检 | 📖 读 |
| `cache.json` | 中间缓存（带台账 sha1 指纹） | ❌ 自动生成 |

## 三、台账怎么写

### 3.1 `求职/已投递的公司.md`

开头一行抬头（**会被用来对账**，写错首页会标红）：

```md
> **已投递合计 N 家** = **已发出 N 家** ＋ **已排期待发 M 家**。约 **K 个**岗位。
```

然后五个小节——**标题照抄**，脚本靠标题认：

```md
## 〇、统计总览          ← 只做展示：### 〇.1 标题 + 一张表；表下以 > 开头的行会显示成说明
## 一、总览              ← 权威名单：一行一家，决定工作台里有几家公司
## 二、按行业线分组       ← 分组浏览用
## 三、已评估后放弃       ← 不计入总数，只在统计页留档
## 四、逐家详情           ← 每家的阶段 / 日期 / 备注正文
```

**§一 总览**（列表头照抄，列顺序有意义）：

```md
| # | 投递日 | 公司 | 岗位 | 城市 | 对口度 | 渠道 | 备注 |
|---|---|---|---|---|---|---|---|
| 1 | 08-28 | **示例能源集团** | 热能工程师 | 北京 | ★★★ | 官网 | 第一志愿 |
| 6 | （日期待补） | **示例数字科技** | 数据分析工程师 | 杭州 | ★☆☆ | 官网 | 投递日忘了记 |
```

- 投递日 `MM-DD` 或 `YYYY-MM-DD` 都行（只写 `MM-DD` 时按「离今天最近的年份」补齐，界面上会标「年份是推断的」）；
- 真忘了就写「（日期待补）」，**照实标，不猜**——首页热力图下面会告诉你几家没日期。

**§二 按行业线分组**：

```md
**A. 能源 / 电力（2 家）**
- **示例能源集团** ｜ 热能工程师 ｜ 北京
```

**§三 已评估后放弃**（标题里的家数会和实际条数对账）：

```md
## 三、已评估后放弃（2 家 · 不计入总数）

**A. 岗位不合适（1 家）**
- **示例矿业集团**（采矿技术岗）｜ 原因：常年驻外、倒班；岗位已下架
```

**§四 逐家详情**（`### 公司 ｜ 岗位` 开头，公司名要能和 §一 对上）：

```md
### 示例能源集团 ｜ 热能工程师
**阶段**：🔵 技术面试 ｜ 证据：HR 邮件约技术面，已回执
**投递日**：2026-08-28
**城市**：北京
**对口度**：★★★
**渠道**：官网
备注：（这一块剩下的正文会整段显示在卡片详情里）
```

九档阶段（`**阶段**` 后面写标签，面试四轮**认文字不认 emoji**，因为都是蓝色圆点）：

| 写这个 | 含义 |
|---|---|
| 🟡 筛选中 | 投出去了，还没有任何回执 |
| 🟣 已测评 · 等面试 | 测评做完了，卡在等面试邀约 |
| 🟠 笔试 | 笔试通知 / 已进笔试 |
| 🔵 AI面试 | AI 面 |
| 🔵 HR面试 | HR 面 |
| 🔵 技术面试 | 技术 / 专业面 |
| 🔵 综合面试 | 终面 / 综合面 |
| 🟩 offer | 拿到 offer |
| 🟥 人才库 | 明确被拒 / 进人才库 |

「证据」里写「回执 / 平台状态 / 已完成」这类词，工作台会把它算成**硬证据**（首页会数「有几家有硬证据」）；
不确定的就写「推定」，不会被算成硬证据。

### 3.2 `求职/面试.md`

```md
## 一、通用问答与追问预案
### 1.1 高频三问
#### 问题一：请做一下自我介绍
（正文）
### 1.2 硕士课题追问预案
**Q1「你的课题一句话是什么？」**
（正文）
### 1.3 本科毕设追问预案
**Q1「毕设做了什么？」**
#### 口述版：近 5 年职业规划
（正文）

## 四、逐家速查
| # | 公司 | 岗位 | 投递日 | 城市 | 对口度 | 状态 |

## 五、公司口碑汇总
### 5.1 逐公司笔记清单
#### 示例能源集团（2 条）
| # | 标题 | 作者 | 时间 | 赞 | 链接 |
### 5.2 按主题归纳
| 主题 | 涉及公司 | 说明 |
```

- §四 那张表是**速查**：§四 详情块里没写的字段（投递日 / 城市 / 对口度 / 岗位）会拿这里的补上，
  界面上标「（速查表补）」——**不把二手值伪装成原文**；
- §5.1 里 `#### 公司（N 条）` 的 N 要和下面的行数一致，公司名要能和台账对上。

## 五、常见问题

**首页顶部标红「缓存已过期」或「不一致」？**
说明 `cache.json` 与台账的 sha1 对不上（直接改了 md 没重跑），或解析出的家数和抬头声明的对不上。
跑 `node build.mjs --scrape`；家数确实对不上就检查 §一 表格的行数与抬头那行。

**「抓取缺口」是什么？**
脚本**不猜**：某个小节标题写法变了、某家公司的阶段文案没认出来、口碑一家都没匹配上……
它会把问题列出来而不是静默填个看起来合理的值。按提示改台账即可。

**改了阶段 / 跟进日期，为什么没进 markdown？**
设计如此：手动状态存浏览器 `localStorage`，不会污染台账。
⚠️ 换浏览器 / 清缓存 / 换电脑会丢，而且**没有导出备份入口**（原作者 2026-10-10 把「导出/导入状态」两项去掉了）；
真需要备份就开 DevTools → Application → Local Storage → 复制 `jobbench.v1` 那条的值。
（个性化存在另一条键 `jobbench.prefs.v1`；它有自己的导出/导入 → 见 `个性化说明.md`。）

**想让首页换张封面？**

> 最省事的做法：打开 `工作台.html` → 顶栏 **🎨** → 「① 封面」→ 选一张图，拖两条滑杆对准位置。
> 改完只影响这台浏览器（不上传、不联网），详见 `个性化说明.md`。
> 下面这条是**换掉包里自带的默认底图**（想让每个人打开都是新图，或想跟着包一起发出去）：

**换封面 = 换 `assets/hero.jpg` 这一个文件**，然后在**本文件夹**跑一次：

```bat
node build.mjs
```

换图时注意两件事（设计里的 `HERO_IMG` 常量是写死的）：

| 约束 | 值 | 为什么 |
|:--|:--|:--|
| 尺寸比例 | **1600×663** | 宽长条封面；尺寸不对会警告“封面底图不是 1600×663” |
| 照片里的水平线（天空与水面交界）位置 | **图片高度的 51.5%** | 「2027 届秋招」那行眉标会**压在这条水平线上**（`alignEyebrow()` 按这个比例算） |

换了别的图（水平线不在 51.5%）也不影响使用，只是眉标会离水面有偏移 ——
改 `app.html` 里那一行 `const HERO_IMG = { w:1600, h:663, pos:0.56, water:0.515 };`
把 `water` 改成你自己的水平线占比就行。

> 包里自带的 `assets/hero.jpg` 是一张中性的黄昏海平线（无人物、无文字、可自由使用）；
> 换成自己的照片、猫、星空、纯色图都可以 —— 它只是一层背景。
> 把图片删了也不会坏：hero 会用一套 CSS 渐变兜底。

**页面打开是空白？**
那是 `app.html`（模板，数据没注入）——请打开 `工作台.html`，或先跑 `node build.mjs`。

**能离线吗？**
能。页面运行期不请求任何外部资源（无 CDN、无网络字体、无统计脚本），所有图形是内联 SVG。

## 六、许可

`app.html` / `build.mjs` / `scrape.mjs` 可自由修改自用。
台账内容（`求职/*.md`）是你自己的数据，**别把别人的公司名单和个人信息一起发出去**。
